Score and criterion tests

What do you want to test?

Suppose a factor model has two loadings, a and b, and we want to test whether they are equal. We can examine the score after imposing equality, or compare the fitting criteria with and without equality. Both are tests of a restriction within a model. Testing whether the whole model fits the population moments exactly is a separate question.

semtest() builds all of these tests. Its first argument is the model fitted under the null. The second, when present, is the alternative.

Question Call Fits needed
Does the whole model fit exactly? semtest(fit) The proposed model
Can the equality restriction be released? semtest(restricted, fit) The restricted model and an alternative specification
Does equality leave the population minimum criterion unchanged? semtest(restricted, fit, statistic = "criterion") Both models

pvalues_nested() also compares nested models, but it tests a different null: that both models fit exactly, using Satorra’s (2000) construction. The nested tests in this vignette allow the larger model to be misspecified, as explained below, so the two need not agree.

We first work through the equality restriction using complete continuous data.

One restriction, two tests

The same factor model before and after imposing equality. Blue paths identify the restriction. Residuals are uncorrelated; intercepts and variances are omitted from the drawing.

The first loading is fixed to 1 in both models, so their factor scales agree. The loadings of x2 and x3 are labeled a and b. Our null is a = b; the loading of x4, variances, and intercepts remain free in both models.

d <- lavaan::HolzingerSwineford1939
model <- "f =~ x1 + a*x2 + b*x3 + x4"
fit <- lavaan::cfa(model, d, meanstructure = TRUE)
restricted <- lavaan::cfa(paste(model, "a == b", sep = "\n"),
                          d, meanstructure = TRUE)
lavaan::coef(fit)[c("a", "b")]
#>         a         b 
#> 0.5466181 0.7042767

Score: evaluate the restricted fit

The score test starts at the restricted fit and measures how strongly the data pull away from a = b once the other free parameters have adjusted. This adjustment is called profiling.

score <- semtest(restricted, fit)
score
#> score test: Common criterion pseudo-target satisfies the restricted model 
#>   type statistic df rank      reference   p_value
#>  score  2.312464  1    1 weighted_chisq 0.1119368
#>                                                     hypothesis
#>  Common criterion pseudo-target satisfies the restricted model

Only the restricted fit needs to be optimized. We reuse fit to supply the alternative parameterization, but an unfitted template works as well:

template <- lavaan::cfa(model, d, meanstructure = TRUE, do.fit = FALSE)
semtest(restricted, template)
#> score test: Common criterion pseudo-target satisfies the restricted model 
#>   type statistic df rank      reference   p_value
#>  score  2.312464  1    1 weighted_chisq 0.1119368
#>                                                     hypothesis
#>  Common criterion pseudo-target satisfies the restricted model

Nested models must use the same data, criterion, factor scaling, and aligned parameterization. Keeping the same model syntax and adding an equality constraint, as above, makes that relationship explicit.

Criterion difference: compare both fits

This test uses the increase in the fitted criterion caused by equality. Both models must be optimized. The reference distribution is calculated at the restricted fit.

criterion <- semtest(restricted, fit, statistic = "criterion")
criterion
#> criterion difference test: Equal population minimum under the shared criterion 
#>                  type statistic df rank      reference   p_value
#>  criterion difference  2.170501  1    1 weighted_chisq 0.1235645
#>                                           hypothesis
#>  Equal population minimum under the shared criterion

For this regular nested comparison, the null says the population minimum criterion is unchanged by the restriction. Under the common-target assumptions discussed below, that is the same equality restriction the score test addresses. Their sample statistics and p-values need not coincide.

Test Statistic p-value
Score 2.3125 0.1119
Criterion difference 2.1705 0.1236

Neither test rejects equality at the 5% level (p = 0.112 and 0.124). Neither test says whether the factor model as a whole fits, and the global test below rejects exact fit. The next section explains what a restriction test means in that case.

What if the factor model is misspecified?

A model can fail to reproduce the population moments even at its best-fitting parameter value. That value is the pseudo-parameter: the minimizer of the population fitting criterion. Under structural misspecification, a = b refers to its two loadings, rather than to parameters of a true factor model. The target can depend on the fitting criterion.

For nested inference, we require a shared criterion and, under the null, a common population minimizer in the restricted model. We also need the usual local regularity conditions, including identification and suitable curvature. A sandwich calculation does not remove those requirements.

It helps to distinguish four issues:

  • Nonnormality: the observations need not follow a normal distribution, even when the model reproduces their means and covariances.
  • Structural misspecification: the model cannot reproduce the target moments; restrictions concern the criterion’s pseudo-parameter.
  • Missing data: FIML uses the observed-data likelihood contributions. Its population target also depends on the observation process and assumptions.
  • Estimated fitting weights: for weighted least squares, the criterion’s weight matrix is estimated from the same data as the sample moments.

Satorra (1989) gives a unified treatment of restriction tests, and Satorra (2000) develops scaled and adjusted versions under nonnormality. The extensions to missing data, structural misspecification, and estimated fitting weights used here are developed in manuscripts in preparation.

How the statistic and its reference are formed

Two separate decisions shape a score test: which matrix weights its quadratic form, and how the underlying matrices are estimated. semtest() takes the first as its weight argument. The second belongs to inference_control(), whose settings can also be passed to semtest() directly.

Write \(s\) for the score at the restricted fit, \(H\) for the curvature of the fitting criterion (how the score changes with the parameters), and \(J\) for the covariance of the score. Profiling uses \(H\) to remove the directions in which the restricted model can still move. Call the profiled score \(\tilde s\), its covariance \(\tilde J\), and the profiled weight matrix \(\tilde M\). The statistic is \[ T = \tilde s^{\mathsf T} \tilde M^{-1} \tilde s . \] Its reference distribution is a weighted sum of independent \(\chi^2_1\) variables, weighted by the eigenvalues of \(\tilde M^{-1} \tilde J\). Here curvature means \(H\) itself, not its inverse.

weight chooses \(M\):

  • "curvature", the default, uses \(H\) itself.
  • "expected_curvature" uses the expected curvature even when \(H\) is the observed curvature. This keeps observed curvature in the profiling, which the limit requires when the model may be misspecified, while weighting by the more stable expected matrix.
  • "score_covariance" uses \(J\). Every eigenvalue is then 1, and \(T\) has a chi-square reference: the score is fully studentized.

The criterion difference always weights by curvature, so weight does not apply to it.

With a single restriction there is a single eigenvalue, and all three weightings give the same p-value, although the statistics differ. The choice matters when several restrictions are tested jointly. Here all three free loadings are held equal:

model3 <- "f =~ x1 + a*x2 + b*x3 + c*x4"
fit3 <- lavaan::cfa(model3, d, meanstructure = TRUE)
equal3 <- lavaan::cfa(paste(model3, "a == b", "b == c", sep = "\n"),
                      d, meanstructure = TRUE)
weights <- c("curvature", "expected_curvature", "score_covariance")
do.call(rbind, lapply(weights, function(w) {
  test <- semtest(equal3, fit3, weight = w)
  data.frame(weight = w, statistic = test$statistic, df = test$df,
             reference = test$reference, p_value = test$p_value)
}))
#>               weight statistic df      reference   p_value
#> 1          curvature  2.901017  2 weighted_chisq 0.3163009
#> 2 expected_curvature  2.710859  2 weighted_chisq 0.2866476
#> 3   score_covariance  3.486518  2          chisq 0.1749493

Conventions: inference_control()

inference_control()
#> semTests inference control
#>   curvature         <by test>
#>   score_covariance  <by test>
#>   weight_effect     estimated
#>   derivative_step   1e-04
#>   tolerance         1e-10
#>   keep              FALSE
  • curvature chooses observed or expected \(H\). The two agree in probability when the model is correctly specified and can differ when it is not.
  • score_covariance chooses how \(J\) is estimated. "centered" subtracts the score means within each group and stays valid when the score does not have mean zero. "uncentered" uses raw score products, which is consistent only when the score has mean zero.
  • weight_effect decides whether estimating the fitting weights counts as a source of sampling variability. It matters only for least squares.
  • derivative_step, tolerance, and keep control the numerical work.

curvature and score_covariance are shown as <by test>: each test picks the convention suited to its null. Overall fit assumes the model holds, since that is its hypothesis, and uses expected curvature with uncentered score products. Nested tests allow the larger model to be misspecified, and use observed curvature with centered products. Supplying a value overrides the choice. These two calls are equivalent:

semtest(equal3, fit3, curvature = "expected")
#> score test: Common criterion pseudo-target satisfies the restricted model 
#>   type statistic df rank      reference   p_value
#>  score  2.817358  2    2 weighted_chisq 0.2684397
#>                                                     hypothesis
#>  Common criterion pseudo-target satisfies the restricted model
semtest(equal3, fit3, control = inference_control(curvature = "expected"))
#> score test: Common criterion pseudo-target satisfies the restricted model 
#>   type statistic df rank      reference   p_value
#>  score  2.817358  2    2 weighted_chisq 0.2684397
#>                                                     hypothesis
#>  Common criterion pseudo-target satisfies the restricted model

With expected curvature, a nested test is valid only when the larger model is correctly specified.

Choosing a p-value calibration

Each test returns a semTests_test object holding its statistic, eigenvalues, reference distribution, and default p-value. pvalues() evaluates other calibrations from that object, without recomputing anything from the fits:

test3 <- semtest(equal3, fit3)
test3$eigenvalues
#> [1] 1.7863363 0.8110898
pvalues(test3, c("ALL", "SB", "SS", "PEBA2"))
#>       all        sb        ss     peba2 
#> 0.3163009 0.3272989 0.3297492 0.3244743 
#> test: score | reference: weighted_chisq | df: 2

ALL evaluates the weighted chi-square distribution itself. SB and SS are the Satorra–Bentler scaled and scaled-and-shifted approximations, and PEBA2 is penalized eigenvalue block averaging with two blocks. These are calibrations of the same statistic. They do not change its curvature, score covariance, or weight. Fully studentized tests accept only STD, since their reference is already chi-square.

The penalized methods were evaluated for the statistics of pvalues() and pvalues_nested(), not for score tests.

Global exact fit

Return now to the separate question: does the unrestricted factor model fit the population moments exactly?

global <- semtest(fit)
global
#> score test: Exact fit against saturated moments 
#>   type statistic df rank      reference     p_value
#>  score  12.02448  2    2 weighted_chisq 0.008817575
#>                           hypothesis
#>  Exact fit against saturated moments
pvalues(global, c("SB", "ALL"))
#>          sb         all 
#> 0.006658492 0.008817575 
#> test: score | reference: weighted_chisq | df: 2

This compares the fitted model with saturated means and covariances, using likelihood scores at the fitted moments. Rejection concerns the whole model, not specifically the equality of a and b. The robust reference handles nonnormality, but the null is still exact fit.

For overall fit, curvature refers to the curvature of the saturated model. The classical discrepancy statistic for the same question is what pvalues(fit) computes, so semtest() does not duplicate it: statistic = "criterion" requires an alternative.

For FIML, likelihood scores are observed-data scores for each missingness pattern, and the score covariance is their empirical covariance, as for complete data. See vignette("fiml-missing-data", package = "semTests") for the missing-data workflow. "STD" gives the non-robust reference, which assumes the information equality:

d_missing <- d
set.seed(1)
d_missing$x2[sample(nrow(d), 60)] <- NA
fit_fiml <- lavaan::cfa(model, d_missing, meanstructure = TRUE,
                        missing = "fiml")
pvalues(semtest(fit_fiml), c("STD", "SB", "ALL"))
#>         std          sb         all 
#> 0.003311375 0.011381091 0.013294814 
#> test: score | reference: weighted_chisq | df: 2

For least squares, the fitting weights are the matrix weighting discrepancies between observed and model-implied moments. They are not sampling weights. Their estimation can contribute to sampling variability when the structural model is misspecified. The contribution vanishes at exact fit.

Here is the equality of all three loadings, fitted by continuous DWLS:

fit_dwls <- lavaan::cfa(model3, d, meanstructure = TRUE, estimator = "DWLS",
                        ordered = FALSE)
equal_dwls <- lavaan::cfa(paste(model3, "a == b", "b == c", sep = "\n"), d,
                          meanstructure = TRUE, estimator = "DWLS",
                          ordered = FALSE)
semtest(equal_dwls, fit_dwls, weight = "score_covariance")
#> score test: Common criterion pseudo-target satisfies the restricted model 
#>   type statistic df rank reference   p_value
#>  score  3.557322  2    2     chisq 0.1688641
#>                                                     hypothesis
#>  Common criterion pseudo-target satisfies the restricted model
semtest(equal_dwls, fit_dwls, weight = "score_covariance",
        weight_effect = "fixed")
#> score test: Common criterion pseudo-target satisfies the restricted model 
#>   type statistic df rank reference   p_value
#>  score  3.080126  2    2     chisq 0.2143676
#>                                                     hypothesis
#>  Common criterion pseudo-target satisfies the restricted model

The default, weight_effect = "estimated", includes the sampling variability of both the sample moments and the estimated fitting weights. "fixed" treats the weights as known, which is correct only when the model fits exactly. Least-squares tests require the centered score covariance, which is the nested default.

These tests currently exclude sampling weights, clusters, nonlinear constraints, and parameter bounds. The ordinal path requires complete, all-ordered data with nonempty pairwise cells; it does not support mixed indicators or pairwise missingness. See vignette("categorical-data", package = "semTests") for ordinal fitting.

Inspecting a result

Pass keep = TRUE to retain the numerical ingredients in $ingredients, and inspect $diagnostics and $provenance when checking a calculation. For example, the nuisance stationarity norm checks that the restricted fit is a stationary point of its own criterion:

score$diagnostics$nuisance_stationarity_norm
#> [1] 1.156657e-07

For ordinal data, the first-stage influence of the thresholds and polychoric correlations is computed in closed form, using lavaan’s score-product convention for the first-stage weight. So is the derivative of the estimated weight, for DWLS and full WLS alike.
